## A. HR rotation of unevaluable seats (src/motor/hr.ts)

At each daily review, AFTER the normal fire/promote/hold pass: any LIVE evolved trader with `(ts - bornAt) >= ROTATION_AGE_MS` (5 days) AND lifetime `db.countTradeCloses(id, bornAt, ts) < minTradesForEvidence` is ROTATED — not fired-with-stigma: forceClose (no-op if flat), book to reserve, status "fired" in the DB sense (roster mechanics identical), but the event is the NEW type `trader_rotated {name, reason, returnedMc}` with reason exactly: "Rotação por falta de evidência: {days} dias sem gerar trades avaliáveis. Sem julgamento — a cadeira precisa produzir informação." The replacement hire for a rotated seat uses a FRESH `randomGenome` (exploration, not exploitation — a mutant of the best is what normal replacement hires already do; rotation exists to inject diversity). Deterministic (pure function of bornAt/ts/counts). Random cohort untouched. Rotation happens at most one trader per review (the oldest unevaluable) to avoid roster churn shocks.
Event plumbing: `trader_rotated` added to events.ts schema (strict), palco-format PT line (`🔄 <strong>{name}</strong> girou a cadeira · devolveu {usd}<br><small>{reason}</small>`), org.history type list in palco-data, mural headline (`🔄 Rotação de cadeira`) + muralVoice pool: ["O RH girou a cadeira de {name}: sem trades suficientes pra julgar, sem julgamento pra carregar. Entra genoma novo.", "{name} saiu sem vermelho no histórico — e sem histórico. A firma precisa de evidência, não de mistério."].

## B. Patience gene — minHoldBars (src/trading/genome.ts + directional-step.ts + cohort.ts)

Genome gains top-level `minHoldBars: number` (int 0..24; 0 = today's behavior). Zod: `.int().min(0).max(24).default(0)` so LEGACY persisted genomes parse clean. randomGenome samples 0..24; mutateGenome gains a tweak op (±bounded, clamped). DirectionalStepState gains `heldBars: number` (missing on legacy state_json → treat as 0 at load): set 0 on the opening bar, +1 each subsequent in-position bar. Enforcement in cohort.stepOneTrader: `if (inPosition && heldBars < genome.minHoldBars) wantLong = true` BEFORE stepDirectional — the exit signal is suppressed until the position matured. Liquidation is NEVER suppressed (engine checks equity first); forceClose (HR/rotation) ignores patience. Random cohort samples the same bounds (control shares limits — honesty invariant). CRITICAL: tick catch-up equivalence test must stay green untouched.
Front touch: PalcoGenome mirror + drawer shows `⏳ segura ≥ {n} barras` chip when minHoldBars > 0; genome struct in palco-data passes it through (params flow already generic? minHoldBars is TOP-LEVEL like leverage — add to structuredGenome + mirror + fixture).
