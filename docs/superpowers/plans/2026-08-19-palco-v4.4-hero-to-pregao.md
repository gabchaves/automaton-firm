# Palco v4.4 — Hero strip moves into a concentrated Pregão panel

User feedback (2026-08-19, verbatim): "essa faixa pode ficar so na primeira
tela de pregao ai vc ja pensa em um painel legal todo concentrado la" — the
global hero-strip (Equity da firma / Controle aleatório / Não fazer nada /
Recorde / Gerações vividas / Dados virgens), currently persistent in
`App.tsx`'s `<header>` across every tab, should live ONLY on Pregão — and
not just relocated as-is, designed as one cohesive "visão geral" panel.

## Design decision

Pregão already has its own per-cohort windowed stat-cards (`CohortStatsGroup`
— Lucro 1h/24h, Trades 24h, Win rate 24h). The global hero-strip carries
complementary, higher-level numbers (absolute equity, do-nothing baseline,
all-time record, gens/dias virgens gate progress). Merge them into ONE
masthead section at the TOP of `PregaoTab.tsx`, in this order:

1. **"Visão geral" row** (the relocated hero-strip, unchanged content/behavior
   — same 6 `.hero-card`s, same `NumberTicker`, same `ShineBorder` on Recorde,
   same stagger-in motion props) — this becomes Pregão's own masthead, not
   App's global one.
2. Directly below: the existing per-cohort `CohortStatsGroup` row (Firma /
   Controle windowed stats) — already there, unchanged.
3. Then the existing chart/positions grid, then the agent P&L + trades row —
   unchanged.

## What moves out of `App.tsx`

Remove the `<section className="hero-strip">` block and its supporting
constants/helpers (`heroCardMotionProps`, `formatCount`, `formatOneDecimal`,
`HERO_STAGGER_DELAY_S`, `HERO_ENTER_DURATION_S`, `VIRGIN_DAYS_GATE`,
`FALLBACK_GEN_START_MC`, `seedMc`/`recordEvolvedMc`/`recordShineThresholdMc`
computed values, the `ShineBorder`/`NumberTicker`/`usd` imports if they
become unused in App.tsx) from `App.tsx`. App's `<header>` keeps: wordmark,
nav links, live dot, `<TickerTape>` — those stay global across all tabs.
`<Confetti feed={...} />` ALSO STAYS in App.tsx unchanged — it's a
page-level celebratory effect triggered by new `record_broken` events
regardless of which tab is open, not part of the hero-strip visually.

## What moves into `PregaoTab.tsx`

The exact hero-strip JSX + its motion/formatting helpers, adapted to read
`snapshot` (already a prop) instead of `cards`/`connected` from App's scope.
Reuse `PregaoTab`'s existing `seedMc` local variable (it already computes
this from `snapshot?.cards.genStartMc`) instead of duplicating it — check
for naming collisions with PregaoTab's existing locals before pasting.
`recordEvolvedMc`/`recordShineThresholdMc` become local to PregaoTab too.

## CSS

`.hero-strip`/`.hero-card` rules in theme.css stay as-is (still used, just
by a different component) — no rule changes needed unless PregaoTab needs
a wrapping section class to visually tie the two card rows ("visão geral" +
per-cohort stats) together as one panel; if so, add a light wrapper
(spacing only, reuse existing tokens) rather than restyling the cards
themselves.

## Testing

- `App.test.tsx`: remove/update assertions that expected the hero-strip on
  every tab; add/keep an assertion that switching tabs away from Pregão does
  NOT render "Equity da firma" etc. (proves it's Pregão-exclusive now).
  Keep nav/live-dot/ticker-tape assertions.
- `PregaoTab.test.tsx`: add assertions for the relocated "visão geral" cards
  (labels + NumberTicker values + ShineBorder-active-on-genuine-record
  behavior — port the existing App-level ShineBorder test case), alongside
  the already-tested per-cohort stat cards. Keep existing Pregão assertions
  intact (positions, agent P&L table, trades list, equity chart).
- Confetti stays covered by whatever App-level test already exercises it
  (unchanged).
